# SAMU MCQs - Medical Practice Platform

Comprehensive medical MCQ practice and exam preparation platform for students across all 6 years of SAMU medical education.

## Features
- **Curated Question Banks**: Thousands of practice MCQs categorized by subjects and topics.
- **Situational Tasks & Clinical Cases**: Real-world medical scenarios for diagnostic and treatment practice.
- **Instant Explanations & AI Insights**: Instant feedback and explanations for every question.
- **Royal Blue & Indigo Clinical Theme**: Modern, accessible interface designed for extended study sessions.
- **Live Deployment**: Hosted on GitHub Pages at [https://mrx4u-ops.github.io/samu_mcq/](https://mrx4u-ops.github.io/samu_mcq/)

## Deployment
The student web application is built and deployed directly to GitHub Pages via the \gh-pages\ branch.
